# Tesztek (v4)

Ebben a projektben a legfontosabb beadandó-szintű lefedettség:
- UI smoke tesztek (kézi, lépésről lépésre)
- API smoke tesztek (kézi HTTP kérésekkel)

## Futási környezet
- MAMP / Apache + PHP
- MySQL (phpMyAdmin)
- Frontend: statikus HTML + JS

Nincs beépített automata teszt runner (pl. Jest/PHPUnit) a projektben,
ezért a beadandóhoz a dokumentált smoke tesztek kerültek mellékelésre.
